# PJC Tweaks - downloads

Get the latest version from [Releases](../../releases/latest):

- **PJC-Tweaks-Setup-x.y.z.exe**: installer (recommended)
- **PJC-Tweaks-Portable-x.y.z.exe**: single exe, nothing installed

PJC Tweaks needs a license key. Once installed, new versions download in the background and install when you close the app, so there's no need to download it again.

This repository only hosts release files; the `latest.json` in each release is the signed update manifest the app checks.
